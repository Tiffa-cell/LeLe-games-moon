# M0 美术验证 · 第一章「月亮的圆缺循环」概念稿

一屏静态概念稿,竖版 iPad(1668 × 2388,11" @2x),无文字、无交互。
美术方向:纪念碑谷式安静极简——低饱和夜空、几何造型、大量留白。

## 画面构成

- **主月亮**:居中偏上的大满月,奶油色平涂 + 同色系浅陨石坑 + 柔和辉光。
- **相位环**:环绕主月亮的 8 枚小月亮,正下方为新月,沿右侧渐盈,
  顶部满月,沿左侧渐亏(北半球视角,亮面方向正确),细点线轨道暗示循环。
- **地面场景**:三层圆弧小山丘,左丘一座小屋(亮着一扇暖窗)和一棵小树,
  右丘一个仰望月亮的小小剪影——孩子视角的比例:天空很大,我们很小。
- **星空**:稀疏星点 + 少量四角星,避开相位环,保持留白。

## 生成方式

概念稿由 `generate_concept.py` 程序化生成(SVG → Chromium 无头渲染 PNG),
构图、相位几何、色板均为参数,可快速迭代:

```bash
python3 generate_concept.py
```

`svg/` 下为矢量源文件,可无损缩放到任意目标分辨率。
