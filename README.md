# 月相

给一个四岁孩子做的月相科普互动应用。一次只讲一个主题，安静、极简、不依赖识字
（每章可以有少量给念的人的中文提词，孩子不用认字也能玩）。
规格见 [SPEC.md](SPEC.md)，路线见 [ROADMAP.md](ROADMAP.md)。

当前进度：**M2.1 第2章「月亮不发光」重做**（M1 底座 + 第1章「圆缺循环」已完成；M0 美术定稿：黛蓝，见 `assets/m0/`）。

## 在 iPad Safari 上打开

整个应用就是一个文件夹：零依赖、零构建。iPad 上的 Safari 不能直接打开本地 HTML 文件，
所以要么发布到网上（方式 A），要么从同一个 Wi-Fi 里的电脑上临时提供（方式 B）。

**A. GitHub Pages（推荐，加到主屏最省事）**

1. 仓库页面 → Settings → Pages → Build and deployment → Source 选 `Deploy from a branch`，
   Branch 选 `main`、文件夹选 `/ (root)`，Save。
2. 等一两分钟，在 iPad Safari 打开 `https://tiffa-cell.github.io/LeLe-games-moon/`。
3. 点分享按钮 → **添加到主屏幕**。以后从主屏图标打开就是全屏，没有地址栏，状态栏跟天空同色。

**B. 局域网临时打开（不发布也能在 iPad 上试）**

在 Mac 上进入仓库文件夹，运行：

```
python3 -m http.server 8000
```

iPad 和 Mac 连同一个 Wi-Fi，在 iPad Safari 打开 `http://<Mac 的 IP>:8000/`
（Mac 的 IP 在 系统设置 → Wi-Fi → 详细信息 里能看到）。这种方式也能添加到主屏，但 Mac 关掉后打不开。

**C. 电脑上直接看**

双击 `index.html` 就能在任何现代浏览器里打开（`file://` 也可以）。
想看 iPad 效果，用浏览器的「响应式设计模式」选 iPad 竖屏。

## 第1章怎么玩

- 开场镜头停在山丘上的小人身上，然后慢慢拉远，看见整个月相环（点一下屏幕可以跳过）。
- 环上有一颗**发着光的小月亮**：拖着它沿环走（在环的任何位置按住拖也可以）。
  中央的大月亮实时跟着变；松手时会轻轻吸附到最近的相位。
- **每经过一个相位小月亮**：它轻轻一跳，天空里那一侧的几颗星「点着」（先闪一下再常亮）。
  星星按绕月亮的方位分成 8 批，跟着手指绕一圈亮起来，走满一圈正好全亮。
- **走完一整圈、回到起点的空心圆**：全屏星星做一次由月亮向外扩散的闪烁波（约 1.5 秒，
  峰值比平时亮得多），小人抬头；然后镜头落到小人身上，停约 2 秒，再缓缓拉回原构图。
  拉回时星空慢慢回暗，可以直接再拖一圈，不用刷新。
- 四角星是通关印记：第一次走满一圈时出现，之后一直留着。
- 右上角三个圆点切换夜色：墨青 / 黛蓝（默认）/ 暗紫。选择会记住。
- 进度（是否通关、圈数）和夜色存在浏览器的 localStorage 里。想重置就清除这个网站的数据，没有账户。

## 章节入口（没有菜单）

- 第1章第一次走满一圈之后，镜头拉回时，**画面下方正中会浮现一个小太阳和一个「→」**（箭头轻轻呼吸缩放）。点它进第2章。
- 第2章过关之后，**左上角出现「←」和一弯小月亮**（箭头同样呼吸缩放），点它回第1章。
- 换章节：第1章有小人，离开时镜头先落到他身上；然后整幅画面淡出、淡入到另一章。第2章是玩家自己的眼睛，没有镜头动作。
- 图标只在可玩时露出来；开场、过关演出、停在小人身上时都藏着。
- 上次停在哪一章会记住（localStorage 的 `moon.progress.current`），下次打开直接回到那一章（前提是第1章确实过过关）。

## 第2章怎么玩：月亮不发光

这一章是**孩子自己的眼睛**：画面只有夜空、中央大月亮、太阳和它的轨道，没有地面、房子和小人，镜头不动。

- 轨道是一个**带俯角的椭圆**（横向长、纵向扁，像从稍高处俯视一个水平圆环）。拖着太阳沿椭圆走（在轨道任何位置按住拖也行，可以绕一整圈）：
  走到**上半段 = 太阳在月亮后方**——太阳变小（0.6 倍）、位于月亮上方、被月亮挡住一部分；
  走到**下半段 = 太阳在月亮前方**——太阳变大（1.3 倍）、位于月亮下方、盖在月亮前面。
- 中央月亮的**亮面永远朝着太阳**：太阳在正后方 → 新月（全暗），在正前方 → 满月，左右 → 弦月，中间是蛾眉月 / 凸月。
  亮面的形状由 SVG `<mask>` 每帧算出来（`MoonMath.litFromOrbit`），没有预制的相位图。
- **三步引导**，屏幕下方一次只显示一句中文提词（给念的人的，字号大）：
  1. 「你能找到满月吗？」——把太阳拖到正前方（±20°）。
  2. 「满月是从哪一边开始变缺的？」——从满月位置往任意一边拖，直到月亮缺掉至少 25%，停住即算。
  3. 「能把月亮藏起来吗？」——把太阳拖到正后方（±20°，新月）。
- **达成判定**：太阳进入目标区域就开始计时，中央月亮外围有一圈细弧线在 1 秒里慢慢填满，填满即完成；
  中途拖出区域弧线清空重来。手指按着不放也算。完成一步：月晕亮一下、天空点亮太阳那一侧的几批星、换下一句提词。
- **进度**：屏幕上方三个小圆点，完成一步点亮一个。三个全亮即过关：星星波从月亮向外扩散、四角星亮起（通关印记），
  然后左上角出现「←」返回键。过关后太阳仍可自由拖着玩；下次进来引导从第一步重新开始。
- **辅助**：屏幕下方边缘一条 8 相位的小月相带，当前相位高亮，方便念的人对照。

## 文件结构

```
index.html         入口（零依赖，双击即开）
theme.js           全部颜色的唯一来源：三套夜色预设（ink / indigo / violet）
css/style.css      布局与动效（颜色只引用 CSS 变量，不写色值）
js/params.js       可调参数（构图、动画节奏、交互手感）
js/moon.js         月相几何（纯函数）：按相位的亮面路径；第2章「亮面朝太阳」的几何（litFromSun）
js/scene.js        分层绘制：第1章 天空 → 星 → 月晕 → 相位环 → 主月亮 → 地面剪影；
                   第2章 天空 → 星 → 月晕 → 轨道后半段 + 后方的太阳 → 主月亮 → 细弧线 → 轨道前半段 + 前方的太阳
js/chapter1.js     第1章：拖拽、过关演出、镜头往返、进度保存
js/chapter2.js     第2章：拖太阳（椭圆轨道）、三步提词引导（±20° / 缺口 ≥ 25%、细弧线停 1 秒、三个进度点）、
                   提词层（HTML：进度点、提词、8 相位小月相带）、过关（星星波）
js/app.js          启动、章节入口（[太阳][→] / [←][小月亮]）与换章节的淡出淡入、夜色切换、屏幕尺寸变化时重建
js/util.js         补间动画、localStorage、章节进度（Progress）
assets/m0/         M0 三张概念稿（定稿：黛蓝 moon-cycle-a-indigo）与生成脚本
assets/icon.svg    主屏图标源文件（icon-180.png 由它渲染）
tools/e2e.js       无头 Chromium 端到端测试（开发用，应用本身不依赖它）
tools/make-icon.js 重新渲染主屏图标
```

## 开发说明

- **颜色铁律**：除 `theme.js` 外任何地方不写色值。自查：
  `grep -rnE '#[0-9a-fA-F]{3,8}\b|rgba?\(' index.html css js` 应该没有输出。
- **画布**：沿用 M0 的 1668 × 2388 坐标系。屏幕更窄长（iPhone）就加长画布、更宽（iPad 横屏）就加宽并补山丘，
  构图不裁切；月亮按比例居上，地面锚定底边。
- **分层**：SVG 里每层一个 `<g class="layer …">`。第1章：天空、星、月晕、相位环、主月亮、地面；
  第2章：天空、星、月晕、轨道后半段（含后方的太阳）、主月亮、细弧线、轨道前半段（含前方的太阳）——太阳穿过左右两端时在前后两层之间换层。
  `Scene.create(svg, w, h, { chapter })` 按章节决定画法：第1章主月亮亮面用 clipPath，第2章用 `<mask>`（`mask-type: alpha`，
  遮罩形状 = 「亮面在右」的相位路径绕月心转到太阳在屏幕上的方向，几何见 `MoonMath.litFromOrbit`）。
- **第2章的几何约定**：轨道角 φ 沿椭圆走，φ = −π/2 是椭圆最上端 = 太阳在月亮正后方（新月），φ = +π/2 是最下端 = 正前方（满月）。
  前后深度 = sin φ：决定亮面占比 (1 + sin φ) / 2 和太阳的缩放；亮面朝向用太阳在屏幕上相对月心的方向（椭圆压扁后与 φ 不同）。
  第1章意义上的相位 = (φ + π/2) / 2π，小月相带按它高亮。
- **提词层**：`#hud`（HTML）只在第2章显示——上方三个进度点、下方一句提词（一次只显示一句）、底边 8 相位小月相带；
  `pointer-events: none`，手指穿过去拖太阳。颜色仍全部走 theme.js 的 CSS 变量。
- **测试**（需要 Playwright，仅开发用）：

  ```
  NODE_PATH=$(npm root -g) node tools/e2e.js              # file:// 打开
  NODE_PATH=$(npm root -g) node tools/e2e.js http://localhost:8000/
  ```

  会在 `tools/shots/` 留下各个阶段的截图（第1章：iPad 竖屏 / 横屏 / iPhone、经过节点点亮、走满一圈的闪烁波、三套夜色；
  第2章：起始构图、太阳躲到月亮后面的新月、蛾眉月、细弧线计时、三步提词、过关的闪烁波、返回键、横屏 / iPhone、回第1章）。
- **主屏图标**：改了 `assets/icon.svg` 之后运行 `node tools/make-icon.js` 重新渲染 PNG。
